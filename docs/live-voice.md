# 直播话术与语音播报

## 开始使用

### 硅基流动与第三方文本模型

在「直播话术 → 配置文本模型」选择「硅基流动」，预设模型选择 `Qwen/Qwen3-8B`，填写自己的硅基流动 API Key 并保存。接口地址已内置为 `https://api.siliconflow.cn/v1`。已有其他模型选择会保留，不会强制更换。该配置也供 AI 助手使用；直播问答在「自动回复设置 → AI回复」中单独配置。

其他服务商选择「其他 OpenAI 兼容服务」，填写 Base URL、模型 ID 和 API Key。兼容标准 `POST /chat/completions`，同时支持流式话术生成和普通问答；可粘贴完整聊天接口地址，保存时自动移除 `/chat/completions` 后缀。本机服务可使用 `http://127.0.0.1:端口/v1`，无需认证的本机服务可填写其支持的占位密钥。这里只支持 Chat Completions 协议，不包含仅支持 Responses 或 Anthropic Messages 的接口。

首次生成话术和开播后的自动续稿均使用这里保存的文本模型、地址及 API Key。更换模型后，新生成的草稿立即使用新配置；已经开始播报的会话需停止并重新开始，续稿才会使用新配置。

所有厂商均可手动填写模型 ID，不受预设列表限制。切换厂商会恢复其上次保存的模型和密钥；在线目录更新不会移除内置的 Qwen3-8B 入口。连接测试检查模型列表接口和密钥，不代表已验证当前模型；不开放模型列表接口的服务商可以保存后直接试用。

硅基流动 Qwen3-8B 请求默认关闭深度思考，以缩短直播回复等待；仅该厂商的该模型携带此参数，其他兼容接口沿用标准请求。协议依据：[硅基流动 Chat Completions 文档](https://docs.siliconflow.cn/docs/api/chat-completions-post)。模型额度、价格和可用性以服务商控制台为准。

### AI 生成与保存话术

在「直播话术 → AI 写直播话术」输入简短产品介绍，按需补充口吻、受众等要求。配置 **AI 助手的文本模型和 API Key**，点击「生成约 3000 字话术」。文字生成使用文本模型，MiMo TTS 用于后续配音，两者分别配置。

生成过程中正文会逐步显示，可以停止生成并保留已生成部分；切换功能页或账号不打断原账号的请求。模型目标为 2700～3300 个非空白字符，页面显示实际字数；如果模型输出长度不足或被截断，会显示提示，不将不完整结果冒充 3000 字成稿。

生成后可直接编辑正文和话术名称，再点击「保存话术」。打开已保存版本后点击「保存修改」更新该版本，或「另存为新话术」保留多个版本。草稿自动保留，但只有点击保存才更新话术库；每个账号最多保存 50 份。载入已有版本会替换当前编辑草稿，先保存需要保留的内容。

下次开播或本地试听，在页面顶部「开播前确认 · 持续讲解」选择已保存版本作为**首段底稿**。页面会列出开场句数、底稿句数和字数，然后点击同一区域内的「开始播报」。播放中切换已保存话术会立即停止旧播报，需核对新底稿与商品资料后再次点击开始；编辑正文仍在下一次开始时生效。顶部会标明当前实际播报的话术名称。

页面下方「AI 写直播话术 · 编辑区」里的「打开已保存话术进行编辑」只切换编辑草稿，不切换本次播报。保存新话术后回到顶部选择；手动修改讲解底稿时，顶部会改为「当前手动填写的讲解底稿」，避免误以为仍在播已保存版本。

话术库按直播账号保存于本机，不自动同步到其他电脑。新保存的话术会一并保存当时的产品介绍、商品参考资料与补充要求，切换时恢复对应资料，避免续稿混用另一款商品的资料。旧版话术没有关联资料，选择时会清空上一款的资料，请在开始前检查补充。删除库中版本会保留编辑草稿及已载入的讲解正文。AI 写稿不会将生成内容自动当作已确认的产品事实。

### 配音与直播

1. 打开「音色克隆」，选择小米 MiMo V2.5 TTS，保存自己的 API Key。默认模型为 `mimo-v2.5-tts`，选择预置音色或填写朗读风格。
2. 选择输出设备，用「合成并播放」试听。密钥按厂商在本机共用；各直播账号分别保存厂商选择、声音参数、音量与设备。
3. 在「直播话术」顶部选择本次讲解底稿；下方可填写开场介绍、手动底稿和「商品要素与参考资料」。开场与底稿各读一次。商品资料供续稿和问答使用，不直接朗读。
4. 配置 AI 助手的文本模型与 API Key，确认顶部的播报内容摘要，点击「开始播报」，**无需开真实直播间，也无需连接中控台**。本地试听保留预合成、暂停、继续、停止及输出设备设置；没填底稿或文本模型密钥会提示先配置。接入观众问答时，先连接中控台再开始播报。
5. 使用问答时，在「自动回复 → 设置 → AI回复」配置 AI 模型和密钥，启用 AI 自动回复、自动发送，再选择「语音播报」或「文字 + 语音」。按需开启「使用产品资料与参考话术回答」。
6. 返回自动回复页面，启动评论监听与回复任务。AI 答案会加入语音队列，在当前句子结束后插播，再继续话术。关闭自动发送时，可以点击答案旁的喇叭手动播放。

### 阿里千问 TTS（Qwen Audio 3.1 Flash）

在「音色克隆 → 厂商」选择「阿里千问 TTS（Qwen Audio 3.1 Flash）」，模型固定为 `qwen-audio-3.1-tts-flash`。

1. 在阿里云百炼控制台获取业务空间 ID，填写 API 基础地址 `https://业务空间ID.cn-beijing.maas.aliyuncs.com/api/v1`。新加坡地域使用 `https://业务空间ID.ap-southeast-1.maas.aliyuncs.com/api/v1`；将示例中的「业务空间ID」替换为实际值，不要填写 OpenAI 兼容地址。
2. 保存该地域的 API Key。千问密钥独立加密存储，不与小米或蓝云共用。
3. 选择龙安欢、龙安灵心、龙安风悦或许南川，按需填写朗读风格，点击「合成并播放」试听。这四种预置音色均支持北京和新加坡。也可填写当前模型和地域支持的其他系统音色，或在阿里平台已创建并绑定当前模型的复刻音色 ID。

千问复用现有本地试听、直播播报、AI 续稿和观众问答队列及缓存；开播前可切换音色。动态语速使用保音高播放调速，避免与合成倍率叠加。本次不包含在软件内创建阿里复刻音色。

调用使用阿里原生 `POST /services/audio/tts/SpeechSynthesizer`，文本、音色、WAV 格式和 `instruction` 放在 `input` 对象中。非流式返回后下载 `output.audio.url`，只允许阿里 OSS 地址，统一使用 HTTPS、禁止重定向，且下载不携带 API Key。合成与下载共用 60 秒取消时限，响应受大小和 WAV 文件标识校验保护。

接口与音色依据：[阿里 Qwen-Audio-TTS HTTP API](https://help.aliyun.com/zh/model-studio/qwen-audio-tts-http-api)、[官方音色列表](https://help.aliyun.com/zh/model-studio/qwen-audio-tts-voice-list)。

### 蓝云 TTS Provider

在「音色克隆 → 厂商」选择「蓝云 TTS（IndexTTS-2.5）」，基础地址默认 `https://tts.lanyun.net`。保存蓝云应用 API Key 后点击「获取音色」，选择音色并使用「合成并播放」试听。也可直接填写蓝云 `voice_id`，或切换 ID 类型填写 `external_voice_id`；两种 ID 不同时提交。模型由蓝云服务端管理，无需填写模型参数。

公共音色的用户 ID 可留空；使用已有私人音色时，填写该音色所属的业务用户 ID（`X-User-ID`），再获取目录。目录、合成和录音下载均使用同一应用与用户身份；更换地址、密钥或用户后需重新获取目录。在「音色克隆」上传 WAV、MP3、OGG、M4A 或 AAC 参考录音，可保存为当前应用与用户的私人音色；本应用限制单文件不超过 10 MiB，并验证文件内容标识。上传成功后自动选中返回的 voice_id，开播前可切换和试听。即时克隆接口与删除音色暂未接入。

支持中文、英文、日文、西班牙文和阿拉伯文，语速为 0.5～2 倍，段间停顿为 0～1000 毫秒，默认 120 毫秒。情感描述留空时使用音色默认表现；填写后通过 `use_emo_text`、`emo_text` 控制情感。该段间停顿控制单次合成内部间隔，分句之间的停顿仍在「直播话术」页设置。

选择蓝云后，本地试听、开场、底稿、AI 续稿与观众问答统一复用当前播放队列及缓存；切换厂商各自保留声音设置，正在播放的会话需要停止后重新开始才应用新设置。

### 动态语速

在「音色克隆 → 播报节奏」配置。默认开启，范围为 **0.85～1.15 倍**，可以调整上下限，也可选择自然讲解、舒缓陪伴或轻快互动。开场、底稿、AI 续稿、观众问答与合成试听均按句子独立设置倍率。

规则会让价格、数字、注意事项、参数及较长句子慢一些，欢迎与互动句快一些，并结合整体节奏和「直播间播报要求」中的常见关键词。例如自习室可以选择「舒缓陪伴」，填写「自习室介绍，安静舒缓，不要太快」。专用要求留空时，参考「AI 写直播话术」的补充要求。这里采用本地规则和关键词判断，不进行额外大模型调用，也不是对任意自然语言指令的完整语义理解。

「合成试听」下方显示分句倍率预览；真正播放时，顶部显示「本句 0.XX×」，悬停可看调整原因。配置按账号自动保存，重启后保留；修改需在停止并重新开始播报后应用。相同文本和配置使用相同倍率，避免随机跳速。

蓝云将单句倍率传给原生 `speech_rate`，播放端保持 1 倍；MiMo 与其他兼容厂商使用 `Audio.playbackRate` 并开启 `preservesPitch`，不擅自添加厂商可能不支持的接口参数。不会把合成倍率和播放倍率相乘。倍率相对于所选音色及风格生成的原始节奏，不代表固定的每分钟字数。

关闭动态语速后，蓝云恢复原先保存的「语速倍率」，MiMo 和兼容厂商按原始音频播放。动态模式不会覆盖蓝云保存的固定倍率。

## 把声音接入直播间

- OBS / 直播伴侣：采集本软件的应用音频，或采集所选输出设备的桌面音频。
- 虚拟声卡：将本软件输出设为虚拟声卡的播放端，直播软件的麦克风设为对应录音端。以 VB-CABLE 的常见命名为例，本软件选择 CABLE Input，直播软件选择 CABLE Output。
- 软件不安装声卡驱动，不接管直播软件的音频设置。请先观察直播软件音量条并做收音测试；同时采集同一路桌面音频和虚拟麦克风会产生重复声音。

## 播放行为

- 「开播前确认」可选择本场音色并点击「试听音色」朗读一小句。MiMo 显示内置音色，蓝云按当前用户身份读取可用目录；OpenAI 兼容厂商及蓝云外部映射 ID 需先在「音色克隆」设置中填写。试听不启动持续播报，切换音色对下一次开始的会话生效。
- 点击「开始播报」时，默认先合成约 30 秒的可播放音频，准备完成后自动开始。可选立即开始、约 15 秒或约 45 秒；界面显示已准备的实际秒数，可随时取消。底稿不足时先调用文本模型生成续稿。未连接中控台即进入本地试听，已连接则关联该直播账号的 AI 语音回复。本地试听途中若要接入实时问答，请连接中控台后停止并重新开始播报。本版本没有统一的平台开播/下播检测。
- 开场与选中的底稿各播放一次。系统以底稿字数为新段落目标（单段 400～4000 字），按剩余待播字数提前调用 AI 助手的文本模型。不同段落轮换讲解角度，参考底稿、商品要素和近几段内容；明显复读会换角度重试，核心参数允许少量重复。新文案进入同一播报队列，原稿不会自动从头重放。模型或 TTS 超时、失败时可能出现等待，无法保证绝对无停顿；失败状态会在界面显示。
- 中英文句末及换行切分话术，长句按最多 220 个 Unicode 字符拆分。预备量按音频实际播放时长计算；准备阶段最多两路并发合成，准备好的音频直接交给播放队列，不重复请求 TTS。播放当前句时继续提前合成后两句，播放始终单通道。选择「立即开始」时仍需等待首句完整合成；接口耗时超过已缓冲音频时仍可能等待。
- 默认句间停顿为 0.15 秒，已有账号保留原设置；连续讲解建议设为 0.1～0.2 秒。顶部显示已预备句数和最近一次合成耗时，方便区分固定停顿与接口等待。
- 全局只有一个语音通道，避免不同账号声音混在一起。切换页面或界面账号不会转移当前播报归属；顶部一直显示播报账号和停止按钮。
- 回复优先于下一句底稿或续稿，但不会截断正在播放的句子。最多积压 30 句插播；每个账号最多同时生成两个 AI 答案，超出时跳过该条 AI 请求。
- 「句末暂停」会播完当前句子后暂停，暂停期间不启动新的续稿或 TTS 预取；「停止语音」立即取消播放、当前 TTS/文本生成和全部预取。重启后从开场第一句开始，迟到的旧结果不能进入新会话。
- 停止自动回复任务、断开控制台会停止关联的直播语音，本地试听不受影响；删除播报账号会停止它的所有语音。关闭/刷新软件后不会自动恢复播报，需重新开始。中控台连接仍在但直播已经结束时，请主动停止语音。
- 修改话术、声音、音量、设备在下次开始时生效；正在直播中的手动试听沿用本次会话声音。想测试新声音，请先停止当前语音。
- MiMo 与兼容厂商合成超时为 60 秒，蓝云合成及下载共用 180 秒时限（客户端设置，并非服务时延保证），音色目录查询超时为 30 秒；播放超时为 180 秒。文本续稿单次最多等待 180 秒，失败最多尝试 3 个主题并显示错误。设备不可用时不会静默切换到扬声器。
- 关键词命中仍优先按原来的文字规则回复；语音输出选项控制 AI 生成的答案。
- 软件最小化后保留语音队列调度；电脑需持续开机运行。OS 休眠、软件退出或中控台失效后不保证继续工作。

## 厂商接入与数据

### 本地保存位置

正常使用 `pnpm dev` 时，Windows 用户数据目录为 `%APPDATA%\oba-live-tool`（可粘贴到资源管理器地址栏）：

- 话术和声音配置：`Local Storage\leveldb` 中的 `voice-config`，保存的版本在各账号的 `savedScripts` 内。
- TTS Key：`tts-keys\mimo.bin`、`lanyun.bin`、`qwen.bin`、`openai-compatible.bin`，使用 Electron `safeStorage` 加密，不能直接当作文本打开。加密上下文与配置目录有关，跨目录恢复需先解密再在目标环境中加密，单独复制 `.bin` 无法保证可用。
- LLM Key：同一 `Local Storage\leveldb` 中的 `ai-chat-storage`，当前随 AI 配置明文持久化，尚未接入 `safeStorage`。AI 助手/写稿和自动回复的配置分别保存。

此前由开发助手启动的隔离预览使用项目下 `test-results\voice-preview-profile`，并通过 `http://127.0.0.1:7777` 访问；它与正常开发启动使用不同的数据目录和来源。正常 `pnpm dev` 固定为 `http://localhost:5173`，端口冲突会直接报错，避免自动切到新端口后读取到空配置。话术还按直播账号隔离，切换账号会看到对应的话术库。

主进程适配器位于 `electron/main/services/tts/providers.ts`，实现统一 `TtsProvider.synthesize` 接口。MiMo、蓝云、阿里千问与兼容厂商共用请求取消、时限、错误处理和有上限的内存音频缓存。

- MiMo：`POST https://api.xiaomimimo.com/v1/chat/completions`；朗读文本放在 `assistant` 消息，风格放在 `user` 消息；从 `choices[0].message.audio.data` 读取 WAV Base64。实现依据：[MiMo V2.5 语音合成官方文档](https://mimo.mi.com/docs/zh-CN/quick-start/usage-guide/audio/speech-synthesis-v2.5)。当前接入预置音色，不包括音色克隆及设计模型。
- OpenAI 兼容语音厂商：基础地址由用户填写，需支持 `POST /audio/speech`、`input`、`voice`、`model`、`response_format: wav` 并返回 WAV 二进制。如果不支持 `instructions`，将朗读风格留空。非此协议的厂商需要增加专用适配器，不能只改地址。
- 蓝云：使用 `X-API-Key` 及可选 `X-User-ID`，通过 `GET /api/v1/voices` 查询音色、`POST /api/v1/tts/synthesize` 合成，再下载响应中的 `audio_url`。仅允许同源下载，并禁止重定向；不使用其 MOSI `/v1/audio/speech` 入口。按音频内容识别 WAV / MP3，忽略接口已废弃的填充词等参数。依据用户提供的《蓝云TTS-API归纳.md》及 [蓝云 OpenAPI](https://tts.lanyun.net/openapi.json)。
- API Key 由 Electron `safeStorage` 在主进程加密，保存于应用用户数据目录 `tts-keys`；前端只查询是否保存，不读回密钥。新密钥保存后输入框清空，不进入 localStorage。
- 话术和非敏感设置保存在 `voice-config`，按账号隔离；已加入原有账号删除及存储清理逻辑。
- 音频只进入最多 32 MiB（按 Base64 长度计）的进程内缓存；重复话术且参数相同可复用，软件重启后重新合成。没有无限量生成并写盘。
- UI 播放器使用 `Audio.setSinkId` 选择声卡，播放后释放 Blob URL。各厂商响应经大小上限及音频文件标识校验后才能播放；蓝云支持 WAV / MP3，其他适配器当前要求 WAV。
- 自动回复读取评论所属账号的配置与参考资料，避免切换界面账号后串用话术；停止之后返回的旧 AI/TTS 结果不能重新开始语音。

`test:voice:pacing` 验证语速范围、内容优先级、直播间要求、旧配置默认值和厂商调速路径；`test:voice:pacing:ui` 用真实浏览器与模拟音频验证三种厂商的实际播放倍率、保音高开关、固定模式、会话内配置快照及刷新后的保存恢复。

这些验证不能替代真实厂商账户接口、音质、虚拟声卡路由和实际直播平台的现场联调。
